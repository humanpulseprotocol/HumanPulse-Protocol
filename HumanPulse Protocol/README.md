# HumanPulse Protocol ($HPP)

## The Global Human Uniqueness Layer for the AI Era

HumanPulse Protocol is the first decentralized infrastructure for **Proof of Unique Humanity** that operates without proprietary hardware, without storing biometric data, and without dependence on central authorities.

### 🫀 How It Works

HumanPulse uses **Proof of Pulse (PoPu)** — a Core 3‑Layer System that cross‑references heartbeat (rPPG), respiration, and an unpredictable on‑chain challenge, secured by zk‑STARK zero‑knowledge proofs. The **$HPP** token powers a usage‑driven, deflationary economy.

### 🛡️ Zero Data Collected. Zero Databases to Hack.

- Biometric data is processed entirely inside the device's TEE.
- Only an anonymous cryptographic proof (zk‑STARK) goes on‑chain.
- Designed to minimize exposure under GDPR, EU AI Act, BIPA, CCPA, and TRAIGA.
